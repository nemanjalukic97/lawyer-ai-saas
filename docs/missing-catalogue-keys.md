# Missing catalogue keys

Not filled by the language-default change. `t()` does not substitute the English sentence. A missing key is printed as the dotted key, for example `signature.dialog.signerName`.

Serbian is the default catalogue and is missing two keys. Slovenian is missing the signature flow. Montenegrin is missing that flow plus address and generate-form fields. There are no Slovenian or Montenegrin users yet, which is why this list is the next item rather than part of the default-language change.

The English column is the source string to translate. Keys are grouped by language.
